# Система расписания занятий

Простое консольное приложение на Python для ведения расписания учебных занятий.

## Назначение

Приложение предназначено для хранения, просмотра и редактирования расписания занятий. Позволяет быстро добавить или удалить занятие с указанием дня недели, времени, предмета, преподавателя и аудитории. Данные сохраняются в локальном JSON-файле, поэтому расписание не теряется между запусками.

## Целевая аудитория

- Студенты, которые хотят вести личное расписание.
- Преподаватели для планирования своих занятий.
- Начинающие программисты как учебный пример консольного приложения на Python.

## Описание предметной области

Предметная область — учёт учебных занятий. Каждое занятие характеризуется:
- днём недели,
- временем начала,
- названием предмета,
- преподавателем,
- номером аудитории.

Расписание — это упорядоченный список таких занятий. Пользователь может просматривать, добавлять и удалять записи. Хранение реализовано в файле `schedule.json` в формате JSON.

## Основные сущности

- **Занятие (Lesson)** — запись о паре:
  - `day` — день недели;
  - `time` — время начала;
  - `subject` — название предмета;
  - `teacher` — преподаватель;
  - `room` — аудитория.

- **Расписание (Schedule)** — список занятий.

- **Хранилище (Storage)** — файл `schedule.json`.

## Основные функции

1. Просмотр текущего расписания.
2. Добавление нового занятия с проверкой ввода.
3. Удаление занятия по номеру.
4. Автоматическое сохранение данных в `schedule.json`.
5. Загрузка расписания при запуске приложения.

## Структура проекта
- `main.py` — точка входа, меню;
- `schedule.py` — функции работы с занятиями;
- `storage.py` — сохранение и загрузка JSON;
- `utils.py` — вспомогательные функции ввода;
- `data/schedule.json` — данные;
- `tests/` — автоматизированные тесты.
