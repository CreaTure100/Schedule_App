# Система расписания занятий

Простое консольное приложение на Python для ведения расписания учебных занятий.

## Назначение

Приложение предназначено для хранения, просмотра и редактирования расписания занятий. Позволяет быстро добавить или удалить занятие с указанием дня недели, времени, предмета, преподавателя и аудитории. Данные сохраняются в локальном JSON-файле, поэтому расписание не теряется между запусками.

## Целевая аудитория

- Студенты, которые хотят вести личное расписание.
- Преподаватели для планирования своих занятий.
- Начинающие программисты как учебный пример консольного приложения на Python.

## Описание предметной области

Предметная область — учёт учебных занятий. Каждое занятие характеризуется:
- днём недели,
- временем начала,
- названием предмета,
- преподавателем,
- номером аудитории.

Расписание — это упорядоченный список таких занятий. Пользователь может просматривать, добавлять и удалять записи. Хранение реализовано в файле `schedule.json` в формате JSON.

## Основные функции

1. Просмотр расписания.
2. Добавление занятия с проверкой ввода (день, время ЧЧ:ММ, пустые поля).
3. Удаление занятия по номеру.
4. Поиск по названию предмета (без учёта регистра).
5. Показ занятий на выбранный день.
6. Сортировка по времени начала.
7. Статус дня (функция из ПР1).
8. Автосохранение и загрузка из `data/schedule.json`.

## Классы

| Класс | Назначение | Атрибуты | Методы и свойства |
|-------|-----------|----------|-------------------|
| `Entity` (абстрактный) | Базовая сущность с ключом | — | `key`*, `matches()`, `__eq__`, `__hash__`, `__repr__` |
| `Teacher(Entity)` | Преподаватель | `name` | `key`, `surname`, `__str__` |
| `Room(Entity)` | Аудитория | `number` | `key`, `__str__` («ауд. 301») |
| `Lesson` | Занятие | `day`, `time`, `subject`, `teacher: Teacher`, `room: Room` | `parse_time()` (static), `start_minutes`, `matches_subject()`, `is_on_day()`, `to_dict()`, `from_dict()` (classmethod), `__str__`, `__repr__`, `__eq__` |
| `Schedule` | Коллекция занятий | `_lessons` | `lessons`, `teachers`, `rooms`, `add()`, `pop()`, `get_teacher()`, `get_room()`, `add_from_dict()`, `from_dicts()` (classmethod), `to_dicts()`, `__len__`, `__iter__`, `__getitem__`, `__str__` |

\* абстрактное свойство, реализуется в `Teacher` и `Room`.

`day`, `time` и `subject` в `Lesson` — свойства с проверкой значений
(`ValueError` при неверном дне, времени или пустом предмете).
Время нормализуется к виду `ЧЧ:ММ` (`9:05` → `09:05`).

## Взаимодействие объектов

- `Lesson` хранит **ссылки** на объекты `Teacher` и `Room`.
- `Schedule` хранит список `Lesson` и следит, чтобы один и тот же
  преподаватель или аудитория были **одним объектом** во всех занятиях
  (`get_teacher()` / `get_room()` возвращают уже известный объект).
- Функции из `schedule.py` работают с коллекциями `Lesson` и вызывают
  методы объектов (`lesson.matches_subject()`, `lesson.is_on_day()`,
  `lesson.start_minutes`), не дублируя их логику.
- `storage.py` превращает JSON ↔ объекты, `main.py` отвечает за меню.

## Формат JSON

Формат полностью совместим с ПР2: список словарей, связанные объекты
хранятся ключевыми строками (имя преподавателя, номер аудитории).

```json
[
  {
    "day": "Понедельник",
    "time": "09:00",
    "subject": "Математика",
    "teacher": "Иванов И.И.",
    "room": "301"
  }
]
```

При загрузке некорректные записи пропускаются с сообщением, остальные
читаются.

## Структура проекта

```
main.py                 # точка входа, меню
schedule.py             # функции над коллекциями занятий
storage.py              # JSON <-> объекты
utils.py                # функции ввода
models/
    __init__.py
    base.py             # Entity
    teacher.py          # Teacher
    room.py             # Room
    lesson.py           # Lesson, DAYS
    schedule.py         # Schedule
data/schedule.json      # данные (создаётся автоматически)
tests/                  # тесты pytest
conftest.py             # общие фикстуры
.flake8                 # настройки flake8
requirements.txt
```

## Требования и установка

- Python 3.10+
- pytest, flake8

```bash
pip install -r requirements.txt
```

```bash
python main.py
```
